# EF Core Interview Notes (Obsidian-Friendly)

This repository contains a structured Obsidian vault section for C# Entity Framework (EF Core).
It is organized for fast recall, interview-ready answers, and spaced repetition (SR/Anki).

## Structure
- `00_TopicMap.md` – central index with wiki-links
- `01_*`...`08_*` – topic folders with notes
- `09_Glossary.md` – concise glossary of core terms
- `templates/EFCore_NoteTemplate.md` – note template

## Usage
- Create a new note per topic using the template.
- Keep answers concise; link to examples and pitfalls.
- Convert Q/A blocks into spaced repetition cards if desired.
